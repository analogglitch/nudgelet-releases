# Nudgelet

A quiet companion for people who find starting tasks hard. Save a thought in one step, get one small next step, and work in short focus sessions with a small dog that keeps you company. No streaks to protect, no guilt for stopping.

**Status:** public beta coming soon for Mac (Apple silicon) and Android. Downloads will appear under [Releases](https://github.com/analogglitch/nudgelet-releases/releases).

- **Your data stays on your devices.** No accounts, analytics, ads or AI services. See the [privacy policy](PRIVACY.md).
- **Found a problem or have a question?** [Open an issue](https://github.com/analogglitch/nudgelet-releases/issues). Please never attach your backup file, because it contains your personal data.

This repository holds releases and documentation only. The app's source code is not published here.
